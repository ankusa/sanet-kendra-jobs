# Naukri Suchna Kendra

Mobile-first job discovery page and printable A4 notice for Sanet Kendra, Pala Fatak, Aligarh.

The scheduled GitHub Action indexes job headlines and source links from Sarkari Result and Sarkari CSC. Imported entries are discovery leads only and must be verified against the recruiting organisation's official notification before being labelled verified.

## GitHub Pages

Create a GitHub repository, push this project to its `main` branch, then choose **Settings → Pages → Source: GitHub Actions**. The included workflow refreshes the index three times daily and publishes the site.
